[Task Skill: orientation-lock-normalization]
每个任务开始前，先执行一次“横屏归一化”，确保设备处于竖屏并关闭自动旋转，再进入业务步骤。

1. 启动阶段强约束（必须先做）
- 在执行任何业务动作前，先检查当前是否为横屏/侧转界面，或系统是否处于“自动旋转”状态。
- 若界面疑似横屏，或看到“自动旋转”按钮处于开启，必须先处理，不得直接进入业务流程。

2. 归一化步骤（直到满足为止）
- 下拉控制中心/快捷设置，找到旋转相关开关（如“自动旋转/竖屏锁定/旋转锁定”）。
- 若当前是“自动旋转”，点击切换为“竖屏锁定”（或等效的关闭自动旋转状态）。
- 若已经是“竖屏锁定”，保持不变并返回任务界面。
- 返回后再次确认界面为竖屏可读布局，再继续业务动作。

3. 失败处理
- 若连续 3 次仍无法恢复竖屏或无法定位旋转开关，执行 `do(action="Take_over", message="请先关闭自动旋转并恢复竖屏，然后按回车继续")`。
- 人工接管结束后，再次确认竖屏状态，然后继续任务。

4. 执行次数约束
- 本技能只在每个任务的启动阶段执行一次归一化；归一化完成后，不要在同一任务中反复执行，除非后续流程再次明显进入横屏导致无法继续。

5. 输出约束
- 每一步只输出一个合法动作，不要把归一化动作和业务动作合并。
